NextGen Dashboard – Week 3 — Intermediate: SQL + Program Performance Dashboard

Step 1: Prepare the Project Files
Ensure that nextgen.db and dashboard.py are saved on your device in the same project folder

Step 2: Install the Required Libraries
The dashboard requires two Python libraries:
Streamlit – Used to create and display the interactive dashboard.
Pandas – Used to load, manipulate and analyse the database data.

Open a terminal and run the following commands:
pip install streamlit
pip install pandas

Step 3: Run the Dashboard
In the same terminal, execute:
streamlit run dashboard.py

The dashboard will automatically open in your default web browser.
If it does not open automatically, copy the local URL displayed in the terminal (usually http://localhost:8501) and paste it into your browser.
